# Apa itu HMI?

HMI, atau lebih tepat disebut **_Animated_ HTML HMI** dalam konteks Visual Monita, merupakan halaman antarmuka yang menampilkan data _realtime_ dalam bentuk animasi atau tampilan bergerak. Kode tipe jenis visual ini adalah `hmi`. Ada bermacam-macam komponen pada jenis visual ini, baik komponen dinamis maupun komponen statis sebagai pendukung visual.

#### Petunjuk penggunaan:

Berkas untuk jenis visual ini didefinisikan dengan membuat atribut `type` berisi nilai `hmi` pada _root tag_ `monita`. Berikut contoh penggunaannya:

```xml
<monita type="hmi"></monita>
```
