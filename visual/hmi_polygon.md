# Poligon

Berikut contoh komponen HMI `polygon` (poligon):

```xml
<polygon>
  <caption>Contoh Poligon 1</caption>
  <x1>100</x1>
  <y1>100</y1>
  <x2>100</x2>
  <y2>200</y2>
  <x3>200</x3>
  <y3>200</y3>
</polygon>
```
