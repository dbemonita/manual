# Apa itu Peta?

Peta, dalam konteks Visual Monita, merupakan halaman antarmuka yang menampilkan data _realtime_ maupun data statis. Baik _marker_ diam maupun _marker_ bergerak (_positioning_). Tujuan dari jenis visual ini umumnya untuk menampilkan ringkasan data dengan basis tampilan geolokasi, serta menunjukkan posisi titik pengukuran dengan sensor GPS. Kode tipe antarmuka ini adalah `map`.

#### Petunjuk penggunaan:

Berkas untuk jenis visual ini didefinisikan dengan membuat atribut `type` berisi nilai `map` pada _root tag_ `monita`. Berikut contoh penggunaannya:

```xml
<monita type="map"></monita>
```
