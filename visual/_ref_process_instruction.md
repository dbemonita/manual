## Penjelasan

> `<?xml version="1.0" encoding="UTF-8"?>`

Format isi dari dokumen ini. XML 1.0.

> `<?visualmonita 5.0?>`

Dokumen ini digunakan pada aplikasi Visual Monita >= 5.0

> `<?title Contoh HMI?>`

Judul dokumen. Dibuat sesingkat dan sejelas mungkin.

> `<?author Andi Prianto?>`

Pembuat dokumen. Nama personal dan/atau divisi.

> `<?revised 2020-01-01 08:00?>`

Tanggal dokumen dibuat atau diperbarui.

> `<?locale id?>`

Bahasa (`id` atau `en`). Umumnya pada format penanggalan.

> `<?development false?>`

Menampilkan atau menyembunyikan:

- _statusbar_
- _tooltip_
- tombol mode XML
- tombol _play/pause_ pada tipe visual HMI
