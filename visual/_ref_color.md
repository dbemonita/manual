# Referensi Warna

Secara umum, Visual Monita 5 mendukung format warna HEX, RGB/RGBA, HSL/HSLA, dan kode warna.
Berikut contoh-contohnya:

| HEX     | RGB              | RGBA                |
| ------- | ---------------- | ------------------- |
| #6495ed | rgb(100,149,237) | rgba(100,149,237,1) |

| HSL              | HSLA                | Kode Warna     |
| ---------------- | ------------------- | -------------- |
| hsl(219,79%,66%) | hsla(219,79%,66%,1) | CornFlowerBlue |

Tidak semua warna memiliki kode warna.
Hanya ada sekitar 146 warna yang memilikinya.
Untuk referensi kode warna dapat dilihat di https://www.w3.org/wiki/CSS/Properties/color/keywords.
