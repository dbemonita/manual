# Termometer

```xml
<thermometer>
  <caption>Contoh Termometer 1</caption>
  <point_id>1001</point_id>
  <height>150</height>
  <x>100</x>
  <y>100</y>
</thermometer>
```

#### Properti selengkapnya:

| Properti           | Tipe Nilai | Nilai Baku    | Keterangan                 |
| ------------------ | ---------- | ------------- | -------------------------- |
| caption            | string     | Thermometer   | Keterangan komponen        |
| point_id           | int        | 0             | Titik ukur                 |
| height             | float      | 0             | Tinggi termometer          |
| fill_color_low2    | string     | DarkSlateGray | Warna liquid batas bawah 2 |
| fill_color_low1    | string     | DarkSlateGray | Warna liquid batas bawah 1 |
| fill_color         | string     | DarkSlateGray | Warna liquid normal        |
| fill_color_high1   | string     | DarkSlateGray | Warna liquid batas atas 1  |
| fill_color_high2   | string     | DarkSlateGray | Warna liquid batas atas 2  |
| tick_color         | string     | SlateGray     | Warna _tick_               |
| unit_color         | string     | DarkSlateGray | Warna satuan               |
| value_visible      | boolean    | _true_        | Menampilkan nilai?         |
| background_visible | boolean    | _true_        | Menampilkan latar?         |
| unit_visible       | boolean    | _true_        | Menampilkan satuan?        |
| tick_visible       | boolean    | _true_        | Menampilkan _tick_?        |
| fahrenheit_visible | boolean    | _true_        | Menampilkan fahrenheit?    |
| interval           | float      | 15            | Interval _tick_            |
| link               | string     | _null_        | Tautan                     |
| x                  | float      | 0             | Posisi: Koordinat x        |
| y                  | float      | 0             | Posisi: Koordinat y        |
