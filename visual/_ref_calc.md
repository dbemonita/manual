# Referensi _Calc_

Fitur ini merupakan proses kalkulasi akhir sebelum data ditampilkan.

## Contoh

- `power; 2` dapat diartikan sebagai `nilai ^ 2`
- `multiply; 100` dapat diartikan sebagai `nilai * 100`
- `divide; 1000` dapat diartikan sebagai `nilai : 1000`
- `add; 10` dapat diartikan sebagai `nilai + 10`
- `subtract; 5` dapat diartikan sebagai `nilai - 5`
- `eval; $ * 2 + 1` dapat diartikan sebagai `nilai * 2 + 1`
