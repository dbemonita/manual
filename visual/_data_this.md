\*) Rentang waktu data:

- `hour`: pukul saat ini menit 00, sampai saat ini. Pengelompokkan data per menit.
- `day`: pukul 00 hari ini, sampai saat ini. Pengelompokkan data per jam.
- `month`: tanggal 1 bulan ini pukul 00:00, sampai saat ini. Pengelompokkan data per hari.
- `year`: tanggal 1 Januari tahun ini pukul 00:00, sampai saat ini. Pengelompokkan data per bulan.
