# Apa itu Dashboard?

Dashboard merupakan halaman antarmuka yang menampilkan data-data ringkasan (_executive summary_). Kode tipe antarmuka ini adalah `dash`.

#### Petunjuk penggunaan:

Berkas untuk jenis visual ini didefinisikan dengan membuat atribut `type` berisi nilai `dash` pada _root tag_ `monita`. Berikut contoh penggunaannya:

```xml
<monita type="dash"></monita>
```
