# Referensi Huruf

Ada beberapa kombinasi huruf yang biasa digunakan web.
Properti huruf terdiri dari beberapa kombinasi huruf yang sejenis sebagai _fallback system_.
Hal ini bertujuan untuk memastikan kompatibilitas antar _browser_ dan sistem operasi (OS).
Kombinasi huruf yang biasa digunakan sebagai berikut:

| ---------------------------------------------------- |
| Georgia, serif                                       |
| 'Palatino Linotype', 'Book Antiqua', Palatino, serif |
| 'Times New Roman', Times, serif                      |
