# Single Bar

Komponen ini berfungsi untuk menunjukkan data titik ukur sesuai nilai yang dikirim oleh _server_. Tampilan komponen ini berbentuk _progress bar_, sehingga lebih sesuai untuk menampilkan data persentase. Berikut contoh komponen `single_bar`:

```xml
<single_bar>
  <point_id>1001</point_id>
</single_bar>
```

Tag pembuka `<single_bar>` tersebut memiliki atribut-atribut seperti yang ada pada tag pembuka komponen `<single_text>`.

Properti-properti yang ada pada komponen ini sama seperti properti-properti yang ada pada komponen `single_text`.
